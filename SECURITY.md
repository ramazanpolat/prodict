# Security policy

## Supported versions

Fixes go into the latest release on [PyPI](https://pypi.org/project/prodict/). Older
versions are not patched.

## Reporting a vulnerability

Report it privately through GitHub: on the
[Security tab](https://github.com/ramazanpolat/prodict/security) choose
**Report a vulnerability**, or open the
[advisory form](https://github.com/ramazanpolat/prodict/security/advisories/new) directly.
Please do not open a public issue.

Include the prodict and Python versions, a minimal reproduction, and the impact you see.
The discussion continues in the private advisory until a fix is released.
